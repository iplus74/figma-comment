Figma 댓글 목록과 댓글과 연결된 디자인을 조회할 수 있는 앱을 구현합니다.

1. 구현 방식
- 런타임
Node.js (Electron 내장)
- 프레임워크
Electron
- UI
Vanilla HTML + CSS + JavaScript
- 빌드 도구
electron-builder
- 설정 저장
브라우저 `localStorage`
- 패키징 형식
macOS `.dmg`, Windows `.exe` (NSIS), Linux `.AppImage` 

2. 댓글 목록
2.1 검색 항목
2.1.1 종류 (type, select field)
- 나를 맨션한 댓글
- 내가 쓴 댓글
2.1.2 최대 개수 (max_num, number field)

2.2 검색 로직
2.2.1 '종류'가 '나를 맨션한 댓글'일 때
나를 맨션한 댓글을 최신순으로 최대 {max_num} 개를 가져옵니다.

2.2.2 '종류'가 '내가 쓴 댓글'일 때
내가 쓴 댓글을 최신순으로 최대 {max_num} 개를 가져옵니다.

2.3 목록 항목
2.3.1 댓글 내용 
2.3.2 작성자
2.3.3 작성일시

3. 댓글 상세보기
댓글 목록의 댓글을 클릭하면 해당 댓글이 포함된 댓글 목록(쓰레드) 과 다지인을 보여줍니다.

3.1 해당 댓글이 포함된 댓글 목록(쓰레드)
- 댓글 내용, 작성자, 작성일시
3.2 해당 댓글의 디자인 노출

3.3 답글 기능
3.4 이전 버튼
이전 화면으로 돌아가는 기능을 제공합니다.
